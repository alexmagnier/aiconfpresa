# AI-конференция — презентация (ReveluxAI)

Статическая HTML-презентация для выступления «AI для бизнеса» (30 мин).

## Деплой на Vercel
1. Vercel → **Add New… → Project** → импортировать репозиторий `aiconfpresa`.
2. Framework Preset: **Other** (это статический сайт, сборка не нужна).
3. Build Command — пусто · Output Directory — пусто (корень). **Deploy**.
4. Готово: презентация откроется на корневом URL (`index.html`).

## Управление
- `←` / `→` или пробел — листать слайды (клик: правая половина — вперёд, левая — назад)
- `S` — заметки спикера (на проекторе не видны)
- `F` — полноэкранный режим
- Клик по скриншоту — увеличить; `← →` / свайп — листать скриншоты; `Esc` — закрыть

## Файлы
- `index.html` — самодостаточная презентация (шрифты — Google Fonts CDN)
- `photo_*.jpg` — 5 скриншотов для слайда «Окружение в действии»
